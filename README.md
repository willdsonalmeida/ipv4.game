
# 🌐 IPv4 Address Master - O Jogo de Redes

Um laboratório prático em formato de jogo para dominar os fundamentos de protocolos de rede, endereçamento IPv4 e cálculos de sub-redes. 

👉 **[JOGUE AGORA: ](https://willdsonalmeida.github.io/ipv4.game/)**

## 🎯 Sobre o Projeto

O **IP Address Master** foi desenvolvido para facilitar o ensino e o aprendizado de Redes de Computadores através da prática ativa com limite de tempo, forçando o raciocínio rápido sobre conceitos essenciais de infraestrutura.

### 🕹️ Módulos de Treinamento

O jogo conta com 4 níveis progressivos:
*   **Classes de IPv4:** Identificação rápida de classes (A, B, C, D) baseada no primeiro octeto.
*   **Conversor Binário:** Construção visual de octetos alternando bits entre 0 e 1 para atingir o valor decimal alvo.
*   **Público vs Privado:** Classificação de IPs roteáveis e IPs da RFC 1918.
*   **Máscaras & CIDR:** Cálculo prático de máscaras de sub-rede decimais e quantidade de hosts úteis.
